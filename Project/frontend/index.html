  • Frontend: HTML, CSS, JavaScript, Chart.js
  • Backend: Flask + Python
  • API: POST /analyze sends input data to the server
  • Processing: carbon, water, category analysis, recommendations
  • Storage: localStorage caches the latest result

Connection flow:

  1. User enters energy and food usage data.
  2. Analyze sends the payload to the Flask API.
  3. The backend computes impact metrics and suggestions.
  4. The frontend renders totals, chart, and insights.
